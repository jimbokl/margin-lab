# Margin Lab · Dealing Desk

Калькулятор маржинального риска клиентского счета для дилинга.

Сайт: https://jimbokl.github.io/margin-lab/

Отдельный статический проект для GitHub Pages. HTML, CSS и JavaScript без runtime-зависимостей. Русский интерфейс, светлая и темная темы, мобильная версия, встроенная легенда настроек.

## Основной режим MVP

Ручной ввод Equity или баланса, общей Used Margin и открытых позиций. Used Margin постоянна. Margin Call — **100%**, Stop Out — **20%**. Нет подключения к MT5, брокеру и клиентским счетам; нет фоновых запросов торговых данных.

Для **каждого инструмента отдельно** бинарный поиск меняет только его цену. Другие инструменты остаются на текущих ценах. Все BUY и SELL выбранного символа участвуют в расчете; цены изменяются на одну абсолютную величину, сохраняя исходную разницу котировок. Поиск идет в обоих направлениях в задаваемом диапазоне. Результат округляется к минимальному шагу цены в сторону срабатывания.

Выводятся Equity, Used Margin, Free Margin, Margin Level, критические цены и расстояния в цене и процентах. Уже достигнутый порог, нулевая маржа и недостижимый уровень отображаются явно.

P&L линейного инструмента = знак × лоты × контракт × (цена − вход) × курс. В режиме баланса прибавляются накопленные своп и комиссия в валюте счета; в режиме текущего Equity они уже включены и повторно не начисляются. Для нестандартных инструментов есть ручная денежная стоимость изменения цены на 1,0 для всей позиции.

## Дополнительные возможности

- Экспозиция: BUY, SELL, нетто и чувствительность Equity по символам.
- Портфельный стресс с индивидуальной чувствительностью позиций, SVG-графиком и матрицей сценариев. Это отдельный режим анализа, не замена независимому поиску цен по символам.
- Дефицит до Margin Call / Stop Out и буфер обеспечения.
- Расширенный расчет маржи по позициям: фиксированная, плавающая, ручная и спецификация Investizo.
- Встречные позиции: сумма, большая сторона либо коэффициент хеджа из спецификации. В двух последних режимах параметры одного символа должны быть согласованы.
- Каталог шести групп MT5 по 161 инструменту: ECN, Standard, Cent и варианты Swap Free. Сохранены два справочных профиля MT4 по 134 инструмента. Поиск, классы активов, контракты, валюты, шаги/лимиты лотов, котировки-снимки, комиссии и свопы.
- Импорт позиций CSV с шаблоном; импорт / экспорт полного сценария JSON; CSV стресс-матрицы; печать; четыре независимых сохраненных сценария.
- Локальное автосохранение и ссылка на расчет. UI не ограничивает число позиций; импорт ограничен размером файла.

## Происхождение спецификаций

Схема проверена по investizo-cabinet-frontend, develop, ревизия 87c894b4e7bfb912832cc2f3850c5a67412fb4d9. Список получен из публичного события markets_list сайта https://investizo.com/markets 23 ноября 2026 года. В проекте хранится только снимок рыночных спецификаций, без исходного кода кабинета, клиентских данных, паролей и гостевых сессий.

Группы MT5 соответствуют стандартным USD-группам из getGroupDefaultByAccountType в investizo-node: REAL\B-USD-{ECN,STD,CNT}-{DEF,SWF}-X. Их эффективные инструменты получены отдельными ответами markets_list для каждого профиля. Это не полный список всех групп сервера: произвольные A-book, тестовые и индивидуальные группы не представлены и не подменяются стандартными. Время последнего тика источник не сообщает; дата получения снимка не означает актуальность котировки.

Forex: маржа Q / плечо / делитель в валюте маржи. CFD: Q × цена / делитель; плечо счета повторно не применяется. В базовой валюте счета маржа Forex постоянна; конвертация базовой валюты через цену учитывается там, где применима. В основном режиме введенная Used Margin имеет приоритет над расчетными маржами строк.

## Границы модели

Курсы пересчета P&L фиксированы в сценариях. Каталог может подставить справочный курс из того же снимка; оператор может изменить его. Нет проскальзывания, расширения спреда, будущего свопа/комиссий и последовательности ликвидации. Значения за Stop Out — гипотетическая переоценка незакрытого портфеля. Нет опционов, инверсных контрактов, ступенчатого плеча и биржевого портфельного обеспечения.

Расширенный хедж использует hedgedMargin / contract, но не воспроизводит все серверные правила MT5, исторический margin_rate, расчет по средневзвешенной цене открытия и групповые исключения. Для сверки с терминалом используйте введенную Used Margin.

## Локальный запуск

Нужен Node.js 22+. Устанавливать пакеты не требуется.

```sh
npm test
npm run dev
# http://127.0.0.1:4173
npm run build
```

В dist/ — готовый сайт. Все пути относительные. Workflow проверяет синтаксис и расчеты перед публикацией main.

## Приватность

Расчеты, импорт и хранение выполняются в браузере. localStorage содержит параметры счета и позиции. JSON, CSV и ссылка могут содержать финансовые данные; получатель видит расчет. URL-фрагмент не отправляется HTTP-серверу. Шрифты Google Fonts при недоступности заменяются системными.

## Будущая автозагрузка клиентских данных

В GitLab найден investizo-node с getApiAccount(server, login), getTradesCurrent(server, login), групповыми инструментами и getMarginLevels(server). Это внутренние сервисы; авторизованный endpoint для публичного сайта не подключен. Текущая версия следует автономному MVP и не имитирует автозагрузку.

Следующему этапу нужен внутренний read-only шлюз с авторизацией оператора, правами на счета и журналом чтения. Ключи MT4/MT5 остаются в инфраструктуре. Исходный backend не изменен и не опубликован.

32 теста: BUY/SELL, фиксированная/плавающая маржа, Used Margin без двойного счета, баланс/Equity, своп/комиссии, хедж, конвертация, ручной P&L, бинарный поиск независимых символов, округление к шагу, недостижимые/достигнутые пороги, CSV, спецификации обоих профилей MT4, шести групп MT5, сопоставление суффиксов .s/.c, применение группы без изменения позиций, отсутствие котировок и 300 случайных портфелей.

## Выбор группы MT5

В настройках выберите группу клиента. Выбор обновляет каталог; уже введенные позиции сохраняют свои настройки до нажатия «Применить группу к позициям». Перед применением показываются изменения имен символов, контрактов, валют, шагов и делителей маржи. Сопоставление выполняется по originalSymbol из API: EURUSD → EURUSD.s для Standard и → EURUSD.c для Cent. Отсутствие инструмента блокирует применение всей группы. Объемы, направление, текущая цена, цена входа, накопленные комиссии/своп и Used Margin сохраняются.

Пороги Margin Call/Stop Out группы в markets_list не передаются — по-прежнему используются фиксированные 100% / 20% MVP. Hedged Margin для MT5 передан как null: скидка за хедж не считается нулевой, режим хеджа требует данных или введенной Used Margin. Комиссия MT5 в backend помечена TODO; интерфейс показывает «не передана API», а не 0.

У ANT отсутствует котировка, у USDVND (и групповых суффиксов) снимок не содержит корректной положительной пары Bid/Ask. Эти инструменты остаются в каталоге, но для расчета требуют ручного ввода цены.

Источник наследования групп: service/trading/tradingSettingsMt5.js и models/mt5/{mt5Groups,mt5GroupsSymbols,mt5Symbols}.js в investizo-node. Групповые overrides уже применены сервером в полученных спецификациях. Рабочие базы, клиенты и учетные данные в репозиторий не входят.
